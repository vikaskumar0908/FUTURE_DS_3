# FUTURE_DS_03 – Marketing Funnel & Conversion Performance Analysis

## 📊 Project Overview

This project was completed as part of the Future Interns Data Science & Analytics Internship – Task 3.

The objective of this project is to analyze marketing campaign data and understand customer conversion patterns, campaign performance, and potential drop-off areas using Power BI.

## 🎯 Objectives

- Analyze total contacts and successful conversions
- Calculate the overall conversion rate
- Analyze conversions across different job categories
- Compare conversion performance by contact method
- Analyze monthly conversion trends
- Understand previous campaign outcomes
- Analyze campaign contact frequency
- Identify patterns that can help improve marketing performance

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Analysis
- Data Visualization

## 📁 Dataset

The project uses the **UCI Bank Marketing Dataset**.

The dataset contains information about bank marketing campaign contacts, including customer demographics, contact methods, campaign details, previous campaign outcomes, and the final subscription outcome.

### Main Target Column

- `y` – Indicates whether the customer subscribed to the term deposit (`yes` / `no`).

## 📈 Dashboard Components

The Power BI dashboard includes:

- Total Contacts
- Successful Conversions
- Unsuccessful Contacts
- Conversion Rate
- Conversion Distribution
- Contacts by Housing Status
- Successful Conversions by Job
- Successful Conversions by Contact Method
- Successful Conversions by Month
- Conversion Rate by Job
- Conversions by Previous Campaign Outcome
- Successful Conversions by Campaign

## 🔍 Key Analysis

The dashboard helps analyze:

- Overall marketing conversion performance
- Customer conversion patterns
- Performance across different contact methods
- Monthly conversion trends
- Previous campaign outcomes
- Campaign contact frequency
- Customer characteristics associated with conversions
